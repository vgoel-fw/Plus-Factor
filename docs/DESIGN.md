# Interface

A single flow, not a system of record: **drop files or paste details -> Analyze -> charts**.

- Home: one drop zone, one text box, Analyze, and a sample-data button.
- Results: four headline numbers; a combined price-and-announcement chart; a supplier table; candidate-market bars with a "pattern holds / weakens" verdict; what Jev read; assumptions made on the user's behalf.
- Any date, number or statement opens the original document in a side drawer with the passage highlighted.
- Modern sans-serif interface. Quoted source text and the document drawer use Century Schoolbook, the court-filing typeface.
- No scores. Verdict pills describe the record ("price moved", "announced, no invoices after"), never legal sufficiency.
